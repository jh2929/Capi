# Capi Desktop

Versión de escritorio de la aplicación Capi.

## Plataformas Soportadas

- Windows 10/11 (x64)
- macOS 12+ (Intel y Apple Silicon)
- Linux (AppImage, .deb, .rpm)

## Construcción

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build
```
