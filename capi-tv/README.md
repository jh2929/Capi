# Capi TV

Versión de Capi optimizada para Smart TVs.

## Plataformas Soportadas

- Android TV
- Tizen (Samsung Smart TV)
- webOS (LG Smart TV)
- Fire TV

## Características

- Interfaz optimizada para遥控器 (mando a distancia)
- Navegación por teclado/direccional
- Modo pantalla completa
- Soporte para resoluciones 4K

## Construcción

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build
```
