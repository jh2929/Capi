# Capi Monorepo

Repositorio monorepo que contiene todas las versiones de la aplicación Capi.

## Estructura

```
Capi/
├── capi-desktop/    # Versión de escritorio (Windows, macOS, Linux)
├── capi-tv/         # Versión para Smart TV
└── capi-android/    # Versión móvil Android
```

## Versiones

| Versión | Descripción | Plataformas |
|---------|-------------|-------------|
| **Capi Desktop** | Aplicación de escritorio completa | Windows, macOS, Linux |
| **Capi TV** | Versión optimizada para Smart TVs | Android TV, Tizen, webOS |
| **Capi Android** | Aplicación móvil nativa | Android 8.0+ |

## Releases

Cada versión tiene sus propias releases con los instaladores correspondientes en la pestaña [Releases](https://github.com/jh2929/Capi/releases) del repositorio.
